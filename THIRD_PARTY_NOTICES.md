# Avisos de terceiros

## Mapa do Brasil em SVG

O arquivo `public/assets/img/brasil-estados.svg` é derivado do projeto
[`luisdalmolin/mapa-brasil-svg`](https://github.com/luisdalmolin/mapa-brasil-svg),
de Luis Dalmolin, disponibilizado sob a licença MIT.

O mapa é usado apenas como representação visual interativa. Os dados de votos,
percentuais e localização são produzidos pelo próprio sistema da campanha.
